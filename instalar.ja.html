インストール

このサイトはアプリとしてインストールできる。ホーム画面にアイコンができ、ネットワークなしで開く。インストールは必須ではない。ブラウザでも同じように読み、学習できる。メニューの名称は端末のもので、版によって少し異なる。

iPhone と iPad · Android · パソコン

iPhone と iPad

  1. Safari（コンパスのアイコンのブラウザ）でサイトを開いてください。ほかのアプリ（メッセージ、メール、SNS）の中のリンクから開いた場合、ページはそのアプリ自身の画面にあり、そこからはインストールできません。「Safari で開く」または「ブラウザで開く」を探すか、アドレスをコピーして Safari に貼り付けてください。
  2. 「共有」をタップしてください。上向きの矢印が付いた四角の印です。iPhone では下のバー、iPad では上にあります。見当たらないときは、先に「···」をタップしてください。
  3. 一覧を上へスクロールし、「ホーム画面に追加」をタップしてください。一覧にないときは、末尾の「アクションを編集…」から追加してください。
  4. 右上の「追加」をタップしてください。
  5. ホーム画面にアイコンができます。一度ネットワークのある状態で開いてください。15 MB を保存します。以後はネットワークなしで開きます。

インストールしたアプリは、Safari とは別に進捗を保存します。移すには、トレーナー下部で、Safari で「進捗を保存」、アプリで「進捗を読み込む」を使ってください。

Android

  1. Chrome でサイトを開いてください。
  2. 右上の「⋮」をタップしてください。
  3. 「ホーム画面に追加」（版によっては「アプリをインストール」）をタップし、続いて「インストール」をタップしてください。
  4. ホーム画面またはアプリ一覧にアイコンができます。一度ネットワークのある状態で開いてください。15 MB を保存します。以後はネットワークなしで開きます。

パソコン

  • Chrome または Edge：アドレスバー右端のインストールの印（矢印の付いた画面）をクリックするか、メニューの「Vocabulario Libre をインストール…」を選び、続いて「インストール」をクリックしてください。
  • Mac の Safari：「ファイル」メニューの「Dock に追加…」。
  • パソコンの Firefox ではインストールできない。サイトはページとして使える。

インストールできないとき

  • プライベートウィンドウやシークレットウィンドウからはインストールできません。通常のウィンドウでサイトを開いてください。
  • ほかのアプリの画面からはインストールできません。端末のブラウザでサイトを開いてください。
  • インストールしない場合：ブラウザのブックマークまたはお気に入りにページを登録してください。同じように読み、学習できます。ネットワークがないと開きません。

削除は他のアプリと同じ。進捗を残すには、先に「進捗を保存」を使う。
