# Lecturas de los libertadores

Reading editions of texts by Bolívar, San Martín and O'Higgins, prepared for
personal study of Spanish, each with a critical apparatus, graded source notes
and a vocabulary trainer built from it. One standard governs all of them:
`POLICY-scholarship-and-compliance.md`.

The authors' texts are public domain. Everything added here — apparatus,
notes, glosses, definitions, code — is released under CC0 1.0.

**Where the work stands and what comes next: `ROADMAP.md`.** Read it first.

---

## Layout

Lecturas are numbered in chronological order; the two-digit number prefixes
every file of a lectura, so any folder — a USB stick, a Drive folder, an
e-reader — sorts the corpus in time.

| File | |
|---|---|
| `corpus.json` | **The manifest.** Every lectura, its number, status and files. Every script reads it. |
| `corpus.py` | Shared helpers: manifest, front matter, body boundaries. `python corpus.py` prints the table. |
| `NN-slug-lectura.md` | **Canonical source** of a lectura. Edit this; PDF and EPUB are generated. |
| `NN-slug-lectura.pdf` / `.epub` | Print and e-reader editions, generated. |
| `NN-slug-register.md` | The lectura's register of guards, checked by `drift.py`. |
| `00-lecturas-de-los-libertadores.md` / `.pdf` / `.epub` | **Governing document**, bilingual (Spanish then English): the corpus in order with signatory, drafting, witnesses, status; rights derivation per author; the shared conventions. Its tables are checked against `corpus.json` by `compliance.py`. Start here. |
| `POLICY-scholarship-and-compliance.md` / `.pdf` | The standard. |
| `ROADMAP.md` | Work plan and hand-off record. |
| `vocab/` | The trainer: one `flashcards.html` covering every built lectura. |
| `index.html` | The front door of a hosted or mirrored copy: every lectura with its files, the trainer, the documents. Generated by `build_index.py`; plain HTML, no script. |

## Read

Open the `.pdf` (bookmarked) or the `.epub` (reflowable, for phones) of any
lectura. Each contains the text in numbered paragraphs, the critical apparatus,
source notes graded for confidence, bibliography, chronology, reference key,
glossary, revision history and rights statement.

## Study vocabulary

Open `vocab/flashcards.html`. One file, no server, no install, no network — it
runs from disk, from VS Code's preview, from a USB stick, from Google Drive's
viewer. Choose a text (or all of them), then *Texto* for the author's words,
*Aparato* for the edition's own editorial prose. Details in `vocab/README.md`.

## Check

    python compliance.py    # governing document + every lectura: declarations, structure, references, counts, rights
    python drift.py         # does each register still describe its edition?
    python verify.py        # word and paragraph counts; add sources to check content
    python verify.py 02 --source witness.txt   # content check for one lectura

Run all three after any edit:

    python compliance.py && python drift.py && python verify.py && python ortografia.py && python reverify.py
    # reverify.py: policy 8.7 — every witness's link, rights line, read date and evidence file (rule 16)
    # ortografia.py: criterion 1 (2010 orthography) on every reading text; rules in ortografia-reglas.tsv
    # prune.py --check: no path an edition, register, the governing document or the manifest cites is in a prune class (8.8); run by compliance.py

Any lectura can be named by number, slug or filename.

## Rebuild

    python build_pdf.py                     # governing document + every built lectura
    python build_index.py                   # index.html, the release's front door (no script, relative links)
    python build_epub.py
    python build_pdf.py -i POLICY-scholarship-and-compliance.md -o POLICY-scholarship-and-compliance.pdf
    cd vocab && python extract_vocab.py && python build_app.py

`build_pdf.py` needs `reportlab` (`pyphen` optional, for hyphenation).
Everything else is standard library. Nothing downloads anything.

## Add a lectura

Follow POLICY § 6. In short: add it to `corpus.json` as *pendiente*; write
`NN-slug-lectura.md` with the front matter the tools read (`# Title`,
`## Subtitle`, `### Author`, `**Place, date**`, `**Versión N.N**`); set the
status to *en curso* and name the edition file; create `vocab/NN/glosses.json`
and `vocab/NN/definitions.json`; write the register; run the three checks;
set *publicada* only when all pass.

## Use, distribution and support

Everything here may be read, copied, redistributed and adapted by anyone, for
any purpose: the texts are public domain and everything added is CC0. Hosting
it, mirroring it, or offering it with a donation or patronage link is within
those terms, provided nothing released under the policy is ever gated behind
payment. Policy § 4 and § 8 (v1.7) set out the standards that make this clean —
first-publication checks, text-not-files, moral rights, a dependency audit,
and the separation of `work/` from the distributable set.

**Release condition (policy § 8).** Nothing is released until every edition in
the release rests only on dates — public domain by age in every layer — and
on the compiler's CC0 waiver, with the evidence inside the release
(`PROVENANCE.md`). A pending item, a declared exception, an unread rights
line, a modern text layer or an open rights question holds that edition back.
`python release.py --check` is the gate; `python release.py` is the only way
a distribution is produced. Donations, patronage, subscriptions and
advertising on the hosting page are welcome and never a condition of access;
no advertisement, tracker, script or asset of a third party ever goes inside
a distributed file. This first release (2026-11-02) carries no support or
hosting link of its own; if the hosting page offers one, it lives on that page
and nowhere in these files, and this paragraph is where a later release would
name it.

**What to publish.** Only the output of `python release.py` (which calls `dist.py`): it writes `dist/`
from the manifest by allowlist (governing document, published lecturas with
PDF, EPUB, register and meaning files, policy, manifest, scripts, trainer)
with a `MANIFEST.sha256`, and `python dist.py --check` — also run by
`compliance.py` — verifies that nothing from `work/` and nothing outside the
allowlist is in it. `python prune.py --dry-run` lists what policy 8.8 removes from the workshop (classes in `work/KEEP.md`) for the compiler's approval; `--apply LIST` deletes exactly that list and records every path. The project zip is the workshop: it holds `work/`, whose
provider files are inventoried with their terms in
`work/PROVIDER-FILES.tsv`, and some of them may not be redistributed. Never
publish the zip.

## What this is not

Not a critical edition, and not to be cited as an established text. Each
lectura records decisions about its text, defines words and identifies names;
it does not interpret what the text says. Where it conflicts with a source,
the source is right and this is wrong.
