複製と改変

フォルダ

作品の全体がこのフォルダである：15 の読解用校訂版とそのソース、語彙トレーナーとそのデータ、それらを規定する文書、 それらを生成し検査するプログラム。README.md がファイルを列挙する（英語）。著者の本文は パブリックドメイン、加えたものはすべて CC0（LICENSE）：フォルダは無条件で複製し、 ホスティングし、改変できる。

現在作成中のものと、今後予定しているもの：今後の予定。

入手の仕方

サイトからは、ファイルごとに：フォルダ lecturas/。丸ごとなら、ミラーのリポジトリ https://github.com/vocabulario-libre/vocabulario-libre.github.io から：一つのアーカイブとして、

https://github.com/vocabulario-libre/vocabulario-libre.github.io/archive/refs/heads/main.zip

またはクローンで、

git clone -c core.autocrlf=false https://github.com/vocabulario-libre/vocabulario-libre.github.io

どちらの場合も、フォルダはその中の lecturas/ である。-c core.autocrlf=false はファイルを公開された ままに保つ。これがないと、Windows の git は既定で改行を書き換え、検査はファイルを変更されたものとして示す。フォルダを 検証するには：その中で sha256sum -c MANIFEST.sha256、または python check_folder.py。

変え方

校訂版の .md ファイルがそのソースであり、PDF と EPUB はそこから生成する。トレーナーは、校訂版と、各校訂版の 訳語と定義のファイル vocab/NN/ から生成する。コマンドは README.md にある。Python 3.9 以降、 reportlab、pyphen が要る。変更のあとは：再構築し、検査する。

校訂版の一語を直すには（ここでは校訂版 12）：

  1. そのソース 12-maximas-para-mi-hija-lectura.md を編集する。
  2. そのファイルを再構築する：python build_pdf.py 12、続いて python build_epub.py 12。
  3. python check_folder.py を実行する。FOLDER CHECK PASS で終わる。

ある語の英語の訳語を変えるには：

  1. その校訂版の訳語ファイル vocab/12/glosses.json を編集する。
  2. トレーナーを再構築する：vocab/ の中で python extract_vocab.py、続いて python build_app.py。
  3. トレーナーのカードを載せるトップページを再構築する：フォルダに戻って python build_index.py。
  4. 上と同じく python check_folder.py を実行する。

フォルダは丸ごと言語モデルに渡せる：展開したアーカイブ、またはクローンと、検査で終わる指示を一つ。指示の例を三つ：

  • 「校訂版 12 の出典についての注記で、この語をこの語に置き換えてください。その校訂版の PDF と EPUB を再構築してください。 check_folder.py を実行し、最後の行を示してください。」
  • 「vocab/12/glosses.json で、この語の訳語をこれに変えてください。トレーナーを再構築し、続いてトップページを再構築してください。check_folder.py を 実行し、最後の行を示してください。」
  • 「check_folder.py を実行してください。配布時からこのフォルダで変わったものと、再構築が要るものを列挙してください。」

検査されること

check_folder.py は各ファイルを MANIFEST.sha256 と照合し、配布時から 変わったものを示す。フォルダ内のプログラムが生成するすべてのファイル ― 校訂版と文書の PDF と EPUB、トレーナー、トップページ、 これらのページ ― を生成し直し、ソースに対して古くなったものを示す。手引きとフォントは目録との照合だけで検査する。語数と正書法の検査を実行する。anon.py を実行する。これは、人の名前やアドレス、あるいはファイルを作った機械の痕跡 ― パス、ユーザー名、タイムゾーン ― を含むファイルを示す。最後の行は FOLDER CHECK PASS、または FOLDER CHECK FAIL と失敗した項目である。

基準の残りは検査しない。compliance.py、drift.py、release.py は校訂版を 方針に照らして検査する。校訂版を作るのに使った作業ファイルが要り、それはこのフォルダにない。 新しい校訂版や校訂注の変更は、ここでは方針に照らして検査されない。MANIFEST.sha256 と PROVENANCE.md は配布物を記述するものであり、変更した複製を記述するものではない。
